# issue #141 の設計：概要の警告バナーとタイルから、失敗したタスクと中止したゴールの件数を外す

対象の issue：[j5ik2o/takt-dash#141](https://github.com/j5ik2o/takt-dash/issues/141)

## 何をどう変えるか

- `frontend/web/src/components/overview-content.tsx`
  - 警告バナー（`.health`）から「失敗・上限超過・PR 失敗のタスクが N件あります。」と「中止したゴールが N件あります。」の2文を消す。
  - 「24時間に完了したタスク」のタイルから「失敗・上限超過・PR 失敗のタスクが N件残っています。」の注記を消す。
- `frontend/web/src/state/dashboard.ts` の `buildOverviewView`
  - `hasAnomalies` から `failedTasks > 0` と `abortedGoals > 0` を外す。バナーを出すかどうかは、判断待ち（`pendingCounts.total > 0`）、応答のないサーバー、応答のないプロジェクト、ログの無音（`silentRunCount > 0`）だけで決める。失敗や中止しかないときに、文の無い空のバナーを出さないためである。
  - `OverviewView` の `failedTaskCount` と `abortedGoalCount`、内部関数 `failedTaskCount` は、読む所が無くなるので消す。`FAILED_TASK_KINDS_LABEL` はプロジェクトのページが使うので残す。

- `docs/taktdash.html`（画面のモック）
  - 概要の「24時間に完了したタスク」のタイルから、失敗したタスクの件数の注記（「失敗したタスクが N件残っています。」「失敗したタスクは残っていません。」）と、その数え方の注記（「失敗・上限超過・PR作成失敗を合わせて数えています。」）を消し、実装と同じ「保存済みの履歴を全プロジェクト分集計しています。」の1文にする。要件定義書の 2.5 がこのモックを画面の基準とし、`frontend/web/README.md` のスクリーンショット比較もこのモックと並べて差分を見るので、モックに失敗の件数を残すと、比べるたびに意図した差分が退行に見える。
  - モックの警告バナー（`healthLine`）は、もとから失敗したタスクと中止したゴールの件数を出していないので変えない。

## 変えないこと（範囲の外）

- バナーに残る文の文面と並び順：判断待ち → 応答のないサーバー（各1文） → 応答のないプロジェクト（各1文） → ログの無音。
- 判断待ちの文の条件。main では、滞留していない判断待ちも1件以上あれば「判断待ちが N件あります。」を出す。滞留の閾値（240分）は判断待ちパネルの「（滞留）」の印にだけ効く。この issue では変えない。
- プロジェクトのページのゴールごとの失敗の表示（`projects-content.tsx`）と、ゴールのページの状態別の欄。
- 判断待ちパネル、ヘッダーの応答なしの注記、ほかの2枚のタイル。
- モックの概要以外のページにある失敗したタスクの件数（判断待ちのページの「異常」の欄の文と、アクティビティのページの「残っている失敗したタスク」のタイル）。この issue が外すのは概要の表示だけである。

## 守る不変条件

1. 概要のどこにも、失敗したタスクの件数の文（「…のタスクが N件あります／残っています」）と「中止したゴールが N件あります」を出さない。
2. バナーは、判断待ち・応答なし・ログの無音のどれかがあるときにだけ出る。失敗と中止の有無と件数は、バナーの有無と中身を変えない。
3. バナーに残る文は、main の文面と並び順のまま出る。

## 壊しうる入力

- 失敗0件・中止0件（いまと同じ表示になること）。
- 失敗と中止が多数で、ほかの異常が無い（main では失敗と中止の文だけのバナーが出る。直したあとはバナーが出ない）。
- 失敗・中止と、判断待ち・応答なし・無音が同時にある（残る文の並びが崩れないこと）。
