# takt-dash-cli

`takt-dash-cli` は、taktDash のバックエンド（`takt-dash-backend`）の gRPC へ接続し、概要に相当する
状態をターミナルへ表示する閲覧専用のコマンドです。状態を書き換えるコマンドは持ちません。

## 起動方法

ワークスペースのルートでビルドし、生成された実行ファイルを起動します。

```sh
cargo build -p takt-dash-cli
./target/debug/takt-dash-cli overview
```

位置引数を省略した場合も `overview` として動作します。

```sh
./target/debug/takt-dash-cli
```

## 引数

| 引数 | 説明 |
|------|------|
| `overview` | 概要を表示します。位置引数を省略した場合の既定の動作です。 |
| `--addr <待ち受けアドレス>` | 接続先の待ち受けアドレスを指定します（例: `127.0.0.1:50051`）。 |
| `--config <設定ファイル>` | バックエンドと同じ形式の設定ファイルのパスを指定します。`listen` を接続先に使います。省略時は `taktdash.config.json` を読みます。 |
| `--help` / `-h` | 使い方を表示します。 |

`overview` 以外のコマンドや未知の引数を渡した場合は、使い方を標準エラーへ表示して終了コード 2 で終わります。

## 表示する内容

概要の表示には、バックエンドの gRPC の `TaktDashService.GetOverview` が返す `DashboardState` を使います。
次の項目を日本語で表示します。

- 最後に読めた時刻
- サーバーごとの名前・機種・接続状態（接続中／応答なし）と台数
- プロジェクトの一覧（名前と説明）と件数
- ゴールの一覧（プロジェクト・ゴール ID・名前）と、タスクの状態ごとの件数（完了・失敗・未着手・実行中）
- run の一覧（プロジェクト・タスク名・要約）と、実行中の run の件数
- 判断待ちの件数と内訳（未回答の問い合わせ・人のマージ待ち）と、その一覧（種別と本文）
- 異常判定の閾値（判断待ちの滞留の分数とログの無音の分数）

一覧が空の項目は「（なし）」と表示します。

## 接続先の解決順

接続先は次の順で解決し、最初に見つかった値を使います。空文字列の値は未設定として扱います。

1. コマンドライン引数の `--addr`
2. 環境変数 `TAKTDASH_BACKEND_ADDR`（`frontend/web` と同じ名前です）
3. `--config` で指定した設定ファイル（省略時は `taktdash.config.json`）の `listen`
4. 既定値 `127.0.0.1:50051`（バックエンドの待ち受けの既定値と同じ値です）

`--addr` などの値が待ち受けアドレスとして解釈できない場合は、既定値へ置き換えず、標準エラーへ理由を表示して終了コード 2 で終わります。

設定ファイルの `listen` は、バックエンドの設定ファイルと同じキーです。新しい独自の設定形式は使いません。

## 接続できないとき

バックエンドへ接続できないときは、接続できない旨と接続先を日本語で標準エラーへ表示し、終了コード 1 で終わります。
接続不能とみなすのは、接続自体に失敗したとき、および接続先が gRPC として応答しないとき（gRPC のステータスが `UNAVAILABLE`・`DEADLINE_EXCEEDED`・`CANCELLED`・`UNKNOWN` のとき）です。
待ち受けはあるが gRPC を話さない相手（接続後に切断する、応答しないなど）は、`CANCELLED` または `UNKNOWN` として同じ分類になります。
この 4 コードは、`frontend/web` の `BackendUnavailableError` が接続不能とする 2 コード（`UNAVAILABLE`・`DEADLINE_EXCEEDED`）より広い集合であり、CLI と web で接続不能とみなす範囲は同じではありません。
バックエンドが応答したうえで概要を返せなかった場合は、接続不能ではなく「概要を取得できませんでした」として区別して表示します。これは `NOT_FOUND`・`PERMISSION_DENIED`・`INTERNAL` など、上記の 4 コード以外の gRPC ステータスすべてに当てはまります。
標準出力へは概要を表示しません。
